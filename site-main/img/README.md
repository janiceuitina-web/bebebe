# Image Assets

## icon.png

Please place the RobBob launcher icon (PNG format) in this directory with the filename `icon.png`.

**Recommended specifications:**
- Format: PNG with transparency
- Size: 64x64px or higher (will be scaled to 32x32px in the UI)
- Style: Should match the RobBob branding

**Note:** A placeholder gradient div is currently being used until the actual icon is provided.
