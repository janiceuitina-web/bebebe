# RobBob Launcher - Официальный Сайт

Минималистичный сайт с эффектом стекла для скачивания RobBob Launcher.

## 🎨 Особенности

- **Glassmorphism дизайн** - современный эффект матового стекла
- **Минимализм** - только самая важная информация
- **Адаптивность** - работает на всех устройствах
- **Анимации** - плавные переходы и эффекты
- **Две вкладки** - Главная и Новости
- **Совпадающая тема** - цвета и стили совпадают с launcher'ом
- **Админ-панель** - управление новостями и настройками (доступ только по URL)

## 🔐 Админ-панель

### Доступ к админ-панели

Админ-панель доступна **только по прямой ссылке**:
```
https://ваш-домен.ru/admin
```

На главной странице сайта нет никаких ссылок на админ-панель.

### Первый вход

При первом входе в админ-панель вам будет предложено установить пароль:

1. Перейдите по ссылке `/admin`
2. Введите новый пароль (минимум 6 символов)
3. Подтвердите пароль
4. Нажмите "Установить пароль"

### Функции админ-панели

**Управление новостями:**
- Добавление новых новостей
- Редактирование существующих
- Удаление новостей
- Пометка "Новое" для актуальных новостей

**Настройки:**
- Версия лаунчера
- Размер файла
- Ссылка для скачивания
- Смена пароля

**Экспорт данных:**
- Скачивание резервной копии в JSON формате

### Безопасность

- Пароль хранится в виде SHA-256 хэша в localStorage браузера
- Сессия активна только в текущей вкладке браузера
- При закрытии браузера требуется повторный вход
- Нет видимых ссылок на админ-панель с главной страницы

**Важно:** Данные хранятся в localStorage браузера. Для синхронизации между устройствами используйте функцию экспорта.

## 🚀 Установка на виртуальный хостинг

### Шаг 1: Подготовка файлов

1. Загрузите все файлы сайта на ваш хостинг через FTP или панель управления хостингом
2. Структура должна быть следующей:
   ```
   public_html/  (или www/, или httpdocs/)
   ├── index.html
   ├── css/
   │   └── style.css
   ├── js/
   │   └── script.js
   └── downloads/
       └── RobBobLauncher-Setup.exe
   ```

### Шаг 2: Создание папки для загрузок

1. **Через FTP-клиент (FileZilla, WinSCP):**
   - Подключитесь к вашему хостингу
   - Откройте корневую папку сайта (обычно `public_html` или `www`)
   - Создайте папку с именем `downloads`
   
2. **Через панель управления хостингом (cPanel, ISPmanager):**
   - Войдите в файловый менеджер
   - Откройте корневую директорию
   - Нажмите "Создать папку" и введите `downloads`

### Шаг 3: Загрузка установочного файла

1. Переименуйте ваш установочный файл launcher'а в `RobBobLauncher-Setup.exe`
2. Загрузите файл в папку `downloads/`

**Важно:** Убедитесь, что расширение файла `.exe` разрешено на вашем хостинге. Некоторые хостинги блокируют исполняемые файлы для безопасности.

### Шаг 4: Альтернативные варианты хранения файла

Если ваш хостинг не разрешает загружать `.exe` файлы, есть несколько решений:

#### Вариант А: Архивирование файла

1. Упакуйте установщик в `.zip` архив:
   ```
   RobBobLauncher-Setup.zip
   ```

2. Загрузите `.zip` файл в папку `downloads/`

3. Измените ссылку в файле [`index.html`](index.html:74):
   ```html
   <a href="downloads/RobBobLauncher-Setup.zip" class="download-btn" id="downloadBtn">
   ```

#### Вариант Б: Использование внешнего хранилища

1. **Google Drive:**
   - Загрузите файл на Google Drive
   - Создайте публичную ссылку (Настройки доступа → Доступ по ссылке)
   - Используйте прямую ссылку для скачивания:
     ```
     https://drive.google.com/uc?export=download&id=FILE_ID
     ```

2. **Dropbox:**
   - Загрузите файл на Dropbox
   - Создайте публичную ссылку
   - Измените `dl=0` на `dl=1` в конце ссылки для прямого скачивания

3. **GitHub Releases:**
   - Создайте репозиторий на GitHub
   - Опубликуйте релиз с прикрепленным файлом
   - Используйте прямую ссылку на файл из релиза

4. Обновите ссылку в [`index.html`](index.html:74):
   ```html
   <a href="ВАШ_ПРЯМОЙ_URL" class="download-btn" id="downloadBtn">
   ```

#### Вариант В: Использование CDN для файлов

Специализированные сервисы для хостинга файлов:
- **MediaFire** - бесплатное хранилище файлов
- **Mega.nz** - безопасное облачное хранилище
- **Яндекс.Диск** - российский облачный сервис

### Шаг 5: Настройка ссылки для скачивания

Откройте файл [`index.html`](index.html:74) и найдите строку:

```html
<a href="downloads/RobBobLauncher-Setup.exe" class="download-btn" id="downloadBtn">
```

Измените путь на один из следующих вариантов:

**Локальный файл на хостинге:**
```html
<a href="downloads/RobBobLauncher-Setup.exe" class="download-btn" id="downloadBtn">
```

**Внешняя ссылка:**
```html
<a href="https://example.com/path/to/RobBobLauncher-Setup.exe" class="download-btn" id="downloadBtn">
```

**Архив:**
```html
<a href="downloads/RobBobLauncher-Setup.zip" class="download-btn" id="downloadBtn">
```

### Шаг 6: Обновление информации о версии (опционально)

В файле [`index.html`](index.html:83-84) вы можете изменить:

```html
<span class="version-badge">v1.0.0</span>
<span class="size-info">~45 MB</span>
```

Замените на актуальную версию и размер вашего файла.

## 🔒 Безопасность

### Защита от прямых ссылок (опционально)

Если вы хотите, чтобы файл скачивался только через сайт, добавьте в папку `downloads` файл `.htaccess`:

```apache
# Запретить прямой доступ
RewriteEngine On
RewriteCond %{HTTP_REFERER} !^https?://ваш-домен.ru [NC]
RewriteRule \.(exe|zip)$ - [F,L]
```

### Проверка на вирусы

Перед загрузкой убедитесь, что ваш установочный файл:
- Подписан цифровой подписью (опционально)
- Проверен антивирусом
- Не содержит вредоносного кода

## 🐛 Решение проблем

### Файл не скачивается

1. Проверьте права доступа к папке `downloads` (должно быть 755)
2. Убедитесь, что файл существует по указанному пути
3. Проверьте, разрешены ли `.exe` файлы на хостинге

### Ошибка 403 Forbidden

1. Проверьте настройки `.htaccess` в корневой папке
2. Убедитесь, что у файлов правильные права доступа
3. Проверьте настройки безопасности хостинга

### Сайт не отображается правильно

1. Очистите кэш браузера (Ctrl+F5)
2. Проверьте, что все файлы загружены
3. Откройте консоль браузера (F12) и проверьте ошибки

### Стили не применяются

1. Убедитесь, что путь к CSS правильный:
   ```html
   <link rel="stylesheet" href="css/style.css">
   ```
2. Проверьте структуру папок на хостинге
3. Убедитесь, что файл `style.css` загружен
